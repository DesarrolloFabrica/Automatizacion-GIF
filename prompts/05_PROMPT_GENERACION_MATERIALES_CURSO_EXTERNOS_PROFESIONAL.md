# 11_PROMPT_GENERACION_MATERIALES_CURSO_EXTERNOS_PROFESIONAL

## Uso del archivo

Este prompt sirve para generar los **insumos derivados del GUION MAESTRO aprobado** para el nivel **CURSO EXTERNOS PROFESIONAL**.

El contenido se produce **un material a la vez**.  
No se inventa información nueva.  
Cada material debe salir exclusivamente de las secciones correspondientes del **GUION MAESTRO verificado** del tema GX.
